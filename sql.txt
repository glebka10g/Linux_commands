distinct - unique in select. Выведет без повторений значения
order by *column* asc - по возрастанию (от 1 до 10)
order by *column* desc - по уменьшению (от 10 к 1)
group by - используется когда есть агрегатные функции

Вопросы:
1. Отличие HAVING от WHERE - where исп для фильтрации на стадии выполнения запроса, having - после выполнения агрегатных функций:
	Порядок выполнения запроса: 1.from, 2.where, 3.group by, 4. having, 5. select, 6. order by
2. UNION и UNION ALL - используется, когда у нас несколько запросов, union-уникальные запросы, union all - с дубликатами
3. Транзакция в БД - единица работы с БД, набор операций которые операции выполняются все вместе или не выполняются вообще
	Пример: списать деньги 1 счет и начислить деньги 2 счет. Выполняется все, либо не выполняется ничего
4. Виды объектов в БД:
	1. Представление - сохраненный запрос. Выглядит как таблица, но данные не хранятся
		Пример: есть запрос с созданием таблицы, используем select* from *Название_представления*.
			Можно сделать представления, чтобы с этими данными работали коллеги
	2. Индекс - позволяет быстро находить строки в таблице. Занимает память, нельзя использовать если в запросе есть like
	3. Триггер - срабатывает при каком-то событии
	4. Функция - тоже сохраненный код, но ВСЕГДА должен возвращать значение
	5. Хранимая процедура - сохраненый код, который выполняется по вызову - CALL

	Отличие ФУНКЦИИ от ХРАНИМОЙ ПРОЦЕДУРЫ:
		1. Функция возвращает значение, процедура не обязана
		2. select функция можно use, процедуру нет
		3. В процедуре можно менять данные, в функции нет
